    The DPI number in a file is only a label

    A digital image is a grid of pixels. That's all the printer gets. The "DPI" (or "resolution") saved in the file is a single number that tells apps like Photoshop, Canva or Word how many of those pixels to fit into one inch when they place the image. Change it from 72 to 300 and the image opens smaller in those apps, but not one pixel changes and the print looks identical at any given size.

    So the question that matters is never "is this file 300 DPI?" but "does it have enough pixels for the size I want?" The answer is a division: pixels ÷ print size in inches = the resolution you'll actually get. A 3000 × 2400 pixel image printed 10 × 8 in gets 300 pixels per inch. Printed 20 × 16 in, it gets 150, whatever the file says.

    That is also why this tool's "save a copy" never resamples. Turning a 72 DPI label into 300 is a few bytes in the header. Making the image genuinely bigger means adding pixels (upscaling), which can't add detail that was never captured.

    DPI and PPI

    PPI, pixels per inch, is the density of pixels in an image at a given print size. DPI, dots per inch, originally meant the ink dots a printer lays down, and a printer uses many dots to reproduce one pixel's color. In practice everyone, including Photoshop's "Resolution" box and the field stored in PNG and JPEG files, uses DPI to mean PPI. When a print shop or marketplace asks for "300 DPI", it means 300 image pixels for every inch of the printed size.

    Why 300 DPI, and when less is fine

    At reading distance (about 30 cm or 12 in) most people can't make out detail finer than roughly 300 pixels per inch, so 300 is the standard for anything held in the hand: photos, cards, book covers and pages. Bigger prints are seen from further away, so they need fewer pixels per inch to look just as sharp. A poster on a wall at 150 to 200 DPI looks fine from a couple of steps back.

    • 300 and up: sharp even under close inspection.
    • 240 to 300: very hard to tell apart from 300.
    • 200 to 240: good for prints and posters seen at arm's length.
    • 150 to 200: acceptable for posters, canvases and most apparel. Many print-on-demand printers accept 150 as their minimum.
    • Below 150: soft or visibly pixelated up close. Only use it for large prints seen from far away.

    Where the DPI is stored, and why apps disagree

    Each format keeps the resolution in its own place, and a file can carry more than one:

    • PNG: the pHYs chunk, stored as pixels per metre (300 DPI is 11811 pixels per metre). Many PNGs have no pHYs at all, and apps then assume 72 or 96.
    • JPEG: the JFIF header near the start of the file, the EXIF block written by cameras and phones, and a Photoshop resolution block. They can disagree, for example JFIF saying 96 and EXIF saying 240. Photoshop, Windows and macOS each pick a different one first, which is why the same file can open at different sizes in different apps. This tool shows all of them and the saved copy sets every one to the same value.
    • TIFF: the XResolution, YResolution and ResolutionUnit tags.
    • WebP: no resolution field of its own. The tool saves WebP files as PNG (lossless) with the DPI you choose, since few print services accept WebP anyway.

    Some apps and services resize on import by this label, so a 300 DPI label can still be worth setting. It just never replaces having the pixels.
